## Cos'è GIT

`Git` è uno strumento per la gestione dei progetti, in particolare dei progetti, in 
particolare dei progetti software, fa parte della categoria dei sistemi **Source

## Cos'è un Repository 

Un *repository* contiene tutti i *file* del progetto e la cronologia della revisione di ogni file.
*è* possibile usare i repository per gestire il lavoro, tenere

### Come creare un repository

Se si ha installato il programma `git` nel proprio *computer*, si può invocare il programma da riga di commando (*shell* o *terminale*), si usa 

```sh
git init
```
Il commando crea una *directory* (cartella) di nome `.git` che conterrà tutte le informazioni sul progetto
